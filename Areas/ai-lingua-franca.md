# 🌐 AI Lingua Franca

> **TL;DR:** Three pillars of AI interoperability: Markdown (universal docs), MCP (universal API), Python (universal automation). If it speaks these, it speaks AI.

> *The native tongues for things and AI that don't speak the same language*

---

## 🗣️ The Three Pillars

| Technology | Icon | Purpose |
|------------|------|---------|
| **Markdown** | 📝 | Universal document format |
| **MCP** | 🔌 | Universal API protocol |
| **Python** | 🐍 | Universal automation language |

---

### 📝 Markdown

The **format of choice** because GitHub Copilot, Python, and almost any AI tooling or LLM can:
- ✅ Read MD text files
- ✅ Find embedded images
- ✅ Generate MD text files with embedded images

---

### 🔌 MCP (Model Context Protocol)

The **API to build a USB-C adapter** for *'any stuff'*

> Think of it as the universal translator that lets AI models connect to any data source, tool, or service seamlessly.

---

### 🐍 Python

**MS Copilot and other AI** leverage Python for:
- 🤖 Automation
- 🧠 Machine Learning
- 👁️ Computer Vision

---

## ✨ Key Benefits

| Benefit | Description |
|---------|-------------|
| 📄 **Text-based** | Human-readable, easy to inspect |
| 🔄 **Version Control** | Git-friendly, track all changes |
| ⚙️ **Automatable** | Python scripts, CI/CD (Jenkins), pipelines |

---

## ⚠️ Challenges

| Source | Difficulty | Notes |
|--------|------------|-------|
| 📘 **MS Word** | 🟡 Medium | Redline conversations are hard to convert to MD, but possible with time and effort |
| 📓 **MS OneNote** | 🔴 Hard | Trickier than MS Word due to notebook structure |

---

*The future speaks Markdown, connects via MCP, and automates with Python.* 🚀
