## 🎯 Repository Purpose & Core Systems

This workspace houses two interdependent, production-grade ML engineering systems:

1. **Search Router v2 (Multi-Index Engine):**
   - Coordinates 4 search engines: **Tantivy BM25** (<1ms broad inverted index), **Graphify AST** (<1ms Tree-sitter code graph), **Ripgrep** (<10ms regex scan), and **ChromaDB** (<50ms vector semantic search).
   - Enforces **local Ollama LLM** (`qwen3.8:27b` via `http://localhost:11434`) for zero cloud spend.
   - Verified by **136 passing unit tests** across `scripts/tests/`.
2. **Burstable MLaaS (Flyte + Ray Hybrid Cloud):**
   - Implements a "surrogate in a box" for aerodynamic turbine & physics simulations.
   - Separates **Macro-Orchestration** (Flyte DAGs, caching, lineage) from **Micro-Compute** (Ray distributed actors, in-memory shared-memory tensors).
   - Targets the **Tri-Environment Model**: Local Mac (Apple Silicon 4-node KinD cluster), AWS EKS (burstable GPU nodes via Karpenter and KubeRay), and On-Premises Firewall VMs.
